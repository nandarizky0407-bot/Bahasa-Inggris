Materi Tenses & Kepemilikan

Pelajari rumus kalimat Positif, Negatif, dan Tanya untuk masing-masing tense sebelum mengerjakan latihan.

Simple Present Tense

Positif (+) S + V1(s/es) + O
Negatif (-) S + do/does + not + V1
Tanya (?) Do/Does + S + V1?

Present Continuous

Positif (+) S + to be + V-ing + O
Negatif (-) S + to be + not + V-ing
Tanya (?) To be + S + V-ing?

Simple Past Tense

Positif (+) S + V2 + O
Negatif (-) S + did not + V1
Tanya (?) Did + S + V1?

Present Perfect

Positif (+) S + have/has + V3 + O
Negatif (-) S + have/has + not + V3
Tanya (?) Have/Has + S + V3?

Have/Has (Kepemilikan)

Positif (+) S + have/has + Object
Negatif (-) S + do/does + not + have
