Grammar Lesson

Like / Likes & Don't Like / Doesn't Like 💚

Learn how to express what you enjoy and what you don't enjoy!

👍 Like / Likes

Use like for I, You, We, They. Use likes for He, She, It.

I like 🍎 apples.
(Saya suka apel.)
They like 🍌 bananas.
(Mereka suka pisang.)
She likes 🥕 carrots.
(Dia (pr) suka wortel.)
He likes 🥦 broccoli.
(Dia (lk) suka brokoli.)

👎 Don't Like / Doesn't Like

Use don't like for I, You, We, They. Use doesn't like for He, She, It.

I don't like 🥒 cucumbers.
(Saya tidak suka mentimun.)
We don't like 🍋 lemons.
(Kami tidak suka lemon.)
He doesn't like 🍅 tomatoes.
(Dia (lk) tidak suka tomat.)
She doesn't like 🥑 avocados.
(Dia (pr) tidak suka alpukat.)

🧠 Quick Summary

I / You / We / They

✅ like / don't like

Example: "I like grapes. I don't like onions."

He / She / It

✅ likes / doesn't like

Example: "She likes strawberries. She doesn't like garlic."
